# python_practice
This is my work during "100 Days of Code: The Complete Python Pro Bootcamp" by dr. Angela Yu. The course consists of 100 lessons, however, this repository contains only those lessons that required me to write code.

Quick summary:
- L16 - simple algorithm taking input from keybord
- L17 - excercise with creating classes in python
- L22 - pong game with score for two players (using turtle library)
- L23 - cars game (using turtle library)
- L24 - working witch files
- L25 - analysis of csv files (using pandas library) and states guessing game (using turtle and pandas library)
- L26 - lists, dictionaries and data frames comprehension practice with nato alphabet project
- L27 - kilometeres / miles coverter with tkinter
- L28 - pomodoro app with tkinter
- L29 - password manager with tkinter
